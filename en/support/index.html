About Shixu

Shixu manages date countdowns and precise timers in one place. Dates use calendar days; timers use elapsed seconds. The app supports Simplified Chinese and U.S. English, with separate date and timer widgets.

Date countdowns and records

How do I create a date countdown?

On Home, add a date record, enter a name and target date, then optionally add a note, event style, or reminder. Remaining days are calendar days: tomorrow shows as 1 day even if it is less than 24 hours away.

How do I edit a date or event style?

Open the date record, choose Edit, update its name, target date, note, or event style, and save. Event styles distinguish themes such as birthdays, health, and work with icons and colors. They do not change the countdown calculation.

What do favorites, long-term plans, and archives do?

Favorites help you filter records and get priority in the date widget. Distant dates may appear under Long-Term Plans, depending on your settings. Expired dates can stay on Home or move to Expired. Manually archived dates can be viewed and restored from Archive.

Can I recover a deleted record?

A regular delete moves a date or timer to Recently Deleted, where you can restore it. Permanent Delete removes it from current records. See the privacy policy for the limits of local recovery copies.

Timers and reminders

How do I create a Duration timer?

Open Timers, add a timer, choose Duration, set the length, and start. It counts down using real elapsed seconds and keeps running when you leave the app. You can manage multiple timers.

How does End Time mode work?

When adding a timer, choose End Time and set a future target time. Once started, the timer keeps its original input mode. Create a new timer if you need the other mode.

Can I pause, resume, or repeat a timer?

Duration timers and repeating End Time timers can pause and resume. Resuming shifts the end time by the frozen remaining duration. A nonrepeating End Time timer has a fixed target and cannot pause or resume; you can stop or edit it. Enable repeating where the timer setup offers that option.

Why did I not receive a reminder?

Check the main reminders switch in Settings, the record’s reminder switch, and iOS notification permission for Shixu. Date reminders are scheduled once for 9:00 a.m. local time on the target date; enabling them later will not send a missed alert. A timer reminder requires a qualifying running timer with a future end time. iOS settings also affect delivery.

How do custom timer sounds work?

In Settings, import audio and select it for timer completion alerts. MP3, AAC/M4A, WAV, and CAF files are supported. Each must have a valid audio track and be under 30 seconds; you can keep up to five. Custom sounds apply to timer alerts, not date reminders.

Home Screen widgets

How do I add a date widget?

Open the iPhone Home Screen widget gallery, find Shixu, and add the small date widget. It shows up to three active date countdowns, prioritizing favorites for selection. Tap it to open Home.

How do I add a timer widget?

In the same widget gallery, add the small timer widget. It shows one timer at a time; tap it to open that timer’s details. The widget is read-only, so timer controls remain in the app.

What if a widget has not updated?

Open Shixu to check the record’s current state and whether it still qualifies for the widget, then return to the Home Screen. The app requests widget updates, but iOS chooses the refresh time. Day changes, timer state changes, and repeat boundaries can be delayed. If needed, remove and add the widget again.
